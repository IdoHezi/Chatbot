# Repository Instructions

- Create code and project deliverables only as Google Colab compatible Jupyter notebooks (`.ipynb`). Do not create standalone source code files such as `.py`, `.js`, or `.ts`.
- Keep notebooks runnable in Google Colab. Put executable code in notebook code cells and include any necessary setup instructions in the notebook.
- Commit every code change to Git.
- Push every completed commit to the configured `origin` remote.
